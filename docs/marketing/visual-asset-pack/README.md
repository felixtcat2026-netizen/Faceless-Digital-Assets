# Visual Brand Asset Pack

Owner issue: NAM-65

This pack defines a reusable visual system for Faceless Digital Assets across storefront, product pages, social posts, and marketplace listings.

## Deliverables
- `brand-style-guide.md` — brand system, palette, typography, composition rules, and marketplace constraints
- `storefront-hero-banner.svg` — storefront/landing banner template
- `social-carousel-template.svg` — 1080x1350 carousel/post cover template
- `social-story-template.svg` — 1080x1920 story/reel cover template
- `product-mockup-creator-launch-kit.svg` — marketplace-ready product mockup
- `product-mockup-carousel-copy-bundle.svg` — marketplace-ready product mockup
- `product-mockup-notion-ops-dashboard.svg` — marketplace-ready product mockup

## Recommended usage
1. Keep the dark editorial background, cyan/violet gradients, and off-white type for every hero asset.
2. Swap only the product title, promise, feature bullets, and preview panel details per offer.
3. Export marketplace images as PNG/JPG from the SVG masters at 2x size.
4. Preserve safe margins and avoid placing key copy inside the outer 64px edge.

## Quick asset mapping
- Storefront hero/banner: `storefront-hero-banner.svg`
- Product thumbnails/listing covers: `product-mockup-*.svg`
- Instagram carousel covers / Pinterest / LinkedIn image posts: `social-carousel-template.svg`
- Story/reel covers / vertical promos: `social-story-template.svg`

## Notes
The visual language matches the premium editorial + performance marketing direction already used in the redesigned storefront and product page work. The system emphasizes clear outcomes, fast implementation, and product-proof panels instead of personality-led branding.
