# Brand Style Guide

## Brand position
Faceless Digital Assets should feel like a premium operating system for digital-product builders: clean, strategic, fast-moving, and conversion-minded. The visual system should communicate clarity, momentum, and practical value without relying on a creator personality.

## Core visual principles
1. Product first
   - Lead with the deliverable, transformation, or preview.
   - Every asset should answer: what is this, who is it for, and what improves after purchase?
2. Premium restraint
   - Use a dark base, high-contrast typography, and selective gradients.
   - Avoid clutter, emoji overload, or loud trend graphics.
3. Proof over decoration
   - UI snippets, checklist fragments, swipe cards, and structured panels outperform abstract filler.
   - Decorative glow should support hierarchy, not replace it.
4. System consistency
   - Reuse the same color roles, card treatments, spacing rhythm, and CTA styling across all channels.

## Palette
- Background / ink: `#0B1020`
- Surface: `#121A2F`
- Surface alt: `#18233F`
- Primary accent: `#67E8F9`
- Secondary accent: `#8B5CF6`
- Highlight accent: `#F472B6`
- Text primary: `#F8FAFC`
- Text secondary: `#B6C2D9`
- Success/support accent: `#34D399`
- Divider/stroke: `rgba(255,255,255,0.12)`

Recommended gradient treatments:
- Hero glow: `#67E8F9 -> #8B5CF6`
- CTA glow: `#67E8F9 -> #06B6D4`
- Highlight chip: `#8B5CF6 -> #F472B6`

## Typography
Preferred stack:
- Headlines: Inter Tight, Sora, or Manrope Semibold/Bold
- Body/UI: Inter or system sans
- Numeric/stat callouts: JetBrains Mono or IBM Plex Mono for utility flavor

Type rules:
- Headlines: sentence case, compact line length, strong verb-driven promise
- Subheads: no more than 2 lines where possible
- Body copy: keep to 1 idea per bullet
- CTA labels: 3-6 words, direct action

## Layout system
### Spacing rhythm
Use an 8px base grid with visible grouping:
- Outer padding: 64px desktop, 40px social portrait, 32px mobile-safe
- Card padding: 24-32px
- Section gaps: 24-48px

### Building blocks
- Eyebrow chip: small all-caps or micro-label for category/use case
- Main headline: outcome-oriented promise
- Support copy: audience + implementation speed
- Proof panel: mock UI, checklist, swipe-card sample, or offer stack
- CTA strip: price/value framing plus action cue

### Shape language
- Large rounded cards: 24-32px radius
- Thin 1px white/low-opacity borders
- Soft blurred glows behind key panels only
- Diagonal or offset panel layering to imply momentum

## Channel adaptations
### Storefront and product banners
- Ratio: 16:9 or 4:3 depending on placement
- Keep copy left-weighted and preview/proof right-weighted
- Maintain one dominant CTA zone

### Marketplace listing images
- Recommended exports: 1600x1200 or 2000x1500
- Keep main title readable at thumbnail size
- Show 1-3 product-proof elements maximum
- Avoid tiny feature copy that disappears in list view

### Instagram / LinkedIn / Pinterest covers
- Carousel/post cover: 1080x1350
- Story/reel cover: 1080x1920
- Use larger title scale and fewer detail bullets than storefront graphics

## Copy framing rules for artboards
Use this sequence when possible:
1. Outcome headline
2. Friction removed or time saved
3. 2-3 tangible deliverables
4. CTA or next-step cue

Good examples:
- Launch your first faceless offer this week
- Swipe-ready copy that turns attention into clicks
- Run launches, follow-up, and fulfillment from one dashboard

## Marketplace readiness checklist
- Title legible at small size
- No critical text inside edge-safe margin
- Export at 2x resolution from SVG master
- Consistent product naming with storefront catalog
- Contrast passes quick visual scan on mobile
- Mockup content reflects actual deliverables, not fake claims

## Production workflow
1. Duplicate the closest SVG master.
2. Replace headline, support copy, and proof-panel details.
3. Export PNG/JPG at target resolution.
4. Review at thumbnail size before publishing.
5. Keep source SVG so the same system can be updated later without rework.
